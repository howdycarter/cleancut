TheSwiftKit Quick Start Guide

Launch your SwiftUI template in minutes.

1. Requirements

  • macOS with Xcode 15 (or newer) installed.
  • Swift 5.9 toolchain (bundled with Xcode 15).
  • Optional: Accounts for Supabase, RevenueCat, TelemetryDeck, OpenAI.

2. Get the Project

  1. Clone or download the repository to your Projects/ folder.
  2. Open TheSwiftKit.xcodeproj in Xcode.

3. Configure Secrets

  1. Duplicate Config/Secrets.sample.swift → Config/Secrets.swift.
  2. Fill in the keys you have today (Supabase URL/key, RevenueCat key, TelemetryDeck App ID, AI backend URL).
  3. Leave unknown values blank — the app falls back to safe defaults until you add real keys.

4. Brand the App

  1. Update AppConfig.appName in Config/AppConfig.swift to your product name.
  2. Change DesignTokens.primaryHex and accentHex in Core/Theme/DesignTokens.swift for your color palette.
  3. Edit the bundle identifier inside project.yml (or Xcode → Signing) to match your domain.

5. Replace Icons

  1. Drop your app icons into Resources/Assets.xcassets/AppIcon.appiconset.
  2. Optionally add an AppLogo image set for onboarding and paywall branding.

6. Run It

  1. Select the TheSwiftKit scheme.
  2. Choose an iOS 16+ simulator or a connected device.
  3. Build & run. Explore the Test Drive screen (DEBUG only) to preview onboarding, auth, paywall, and notifications.

Launch Checklist

  • ☐ Supabase tables & policies applied
  • ☐ RevenueCat products mapped and API key set
  • ☐ TelemetryDeck App ID configured
  • ☐ AI backend running or disabled
  • ☐ App icons, name, bundle ID finalized
  • ☐ Test Drive / demo screens removed for release builds
